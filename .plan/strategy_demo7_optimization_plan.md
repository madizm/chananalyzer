# strategy_demo7 后续优化计划

## 背景

当前 `strategy_demo7.py` 已经形成一套 30M 买点训练流程：

- 数据源：`DATA_SRC.CACHE_DB`
- 主级别：30M
- 父级别：DAY
- 子级别：15M
- 买点类型：`1,1p`
- 评估输出：整体指标、Top 5% / 10% / 20% / 30% 分层命中率与收益、特征重要性、运行参数

最近一轮结果显示模型具备一定排序能力，Top 分层收益和命中率明显高于整体样本，但仍需要验证这种效果是否稳定、是否依赖特定时间段，以及哪些特征是真正贡献增益的。

这说明当前模型主要依赖父级别环境、本级别波动和近期收益结构，而不是子级别特征。

## 阶段 1：增强评估可信度

### 1.1 增加测试集时间段拆分评估

目标：观察模型在不同月份或不同时间段上的效果是否稳定。

建议在 `metrics.json` 中新增 `time_period_metrics`，按测试集时间分组输出：

- `period`
- `sample_count`
- `positive_rate`
- `auc`
- `average_precision`
- `avg_realized_return`
- `avg_forward_return`
- `top5pct_hit_rate`
- `top5pct_avg_realized_return`
- `top10pct_hit_rate`
- `top10pct_avg_realized_return`
- `top20pct_hit_rate`
- `top20pct_avg_realized_return`

判断标准：

- 多数时间段 AUC 高于 0.55，说明排序能力相对稳定。
- Top5% / Top10% 的平均收益持续高于整体测试集，说明模型对交易筛选有实际价值。
- 如果只在单一月份表现很好，需要警惕阶段性行情过拟合。

### 1.2 增加 walk-forward 验证

目标：模拟真实滚动训练和未来测试。

建议增加一种验证模式，例如：

- 训练：2024-01 至 2025-12，测试：2026-01
- 训练：2024-01 至 2026-01，测试：2026-02
- 训练：2024-01 至 2026-02，测试：2026-03

每个窗口输出与整体测试一致的指标。

判断标准：

- 每个窗口 Top 分层收益应大体为正。
- AUC 和 AP 不要求每期都高，但不能频繁跌到随机水平以下。
- 如果越靠近近期表现越差，需要重新检查特征是否适应最新行情。

## 阶段 2：特征有效性验证

### 2.1 做特征组消融实验

目标：判断父级别、子级别、上一个买卖点、红绿成交额等特征是否真正贡献增益。

建议跑以下配置：

- 仅 30M 本级别特征
- 30M + 上一个买卖点特征
- 30M + DAY 父级别特征
- 30M + 15M 子级别特征
- 30M + DAY + 15M
- 30M + DAY + 15M + 红绿成交额归一化特征

对比指标：

- AUC
- Average Precision
- Top5% / Top10% 命中率
- Top5% / Top10% 平均收益
- 分时间段稳定性

判断标准：

- 如果某组特征只提升整体 AUC，但降低 Top5% 收益，优先以 Top 分层收益为准。
- 如果某组特征在多个时间段都提升，保留优先级更高。
- 如果某组特征重要性长期接近 0，可以考虑删除以降低噪音。

### 2.2 检查子级别 15M 特征

当前 15M 子级别特征已经确认可以正确加载，并且部分特征进入模型重要性。后续需要确认它们在不同时间段是否稳定贡献增益。

建议先输出子级别特征覆盖率：

- `child_klc_count` 的分布
- `child_bi_count` 的分布
- `child_latest_bsp_exists` 的比例
- `child_return` / `child_range` 的分布

判断标准：

- 如果大量样本 `child_*` 为 0 或缺失，说明 15M 对齐或覆盖不足。
- 如果有充分变化但重要性仍低，说明当前子级别特征可暂缓扩展。

### 2.3 红绿成交额归一化特征继续观察

当前红绿成交额特征重要性偏低，但没有明显破坏模型结果。

建议暂时保留，并在消融实验中验证：

- 保留红绿成交额特征
- 移除红绿成交额特征

重点比较 Top5% / Top10% 平均收益，而不是只看 AUC。

## 阶段 3：目标定义优化

### 3.1 检查 horizon 对结果的影响

当前已测试过 `horizon=5`，建议继续固定其他配置，比较：

- `horizon=3`
- `horizon=5`
- `horizon=8`
- `horizon=10`

判断标准：

- 短 horizon 更适合高频择时，但噪音更大。
- 长 horizon 更容易捕捉趋势，但可能引入更多持仓过程风险。
- 最终优先选择 Top 分层收益稳定、最大回撤可控的 horizon。

### 3.2 增加交易成本后的评估

目标：让指标更接近真实交易。

建议在评估中增加假设成本：

- 手续费
- 滑点
- 卖出冲击或固定扣减

输出：

- `avg_realized_return_after_cost`
- `top5pct_avg_realized_return_after_cost`
- `top10pct_avg_realized_return_after_cost`

判断标准：

- 扣成本后 Top5% / Top10% 仍为正，模型才具备进一步回测价值。

## 阶段 4：模型层优化

### 4.1 RandomForest 小范围调参

当前 RandomForest 是稳健基线，建议先做小范围参数网格：

- `max_depth`: 3, 4, 5, 6
- `min_samples_leaf`: 3, 5, 10, 20
- `max_features`: `sqrt`, `log2`, 0.5
- `n_estimators`: 300, 500

评估标准：

- 以 walk-forward 的 Top5% / Top10% 收益和稳定性为主。
- AUC 只作为辅助排序指标。

### 4.2 引入 XGBoost 对照

XGBoost 更擅长非线性和特征交互，但更容易过拟合。

建议先使用保守参数：

- `max_depth`: 2 或 3
- `learning_rate`: 0.03 到 0.08
- `n_estimators`: 200 到 500
- `subsample`: 0.7 到 0.9
- `colsample_bytree`: 0.7 到 0.9
- `scale_pos_weight`: 根据训练集正负样本比例计算

判断标准：

- 如果 XGBoost 只提升训练集、不提升 walk-forward 测试，不切换。
- 如果 XGBoost 在 Top 分层收益和时间段稳定性上都优于 RandomForest，再考虑作为主模型。

## 阶段 5：交易化评估

### 5.1 增加 Top 分层模拟持仓评估

目标：从分类指标转向交易收益指标。

建议按模型分数排序，只交易：

- Top5%
- Top10%
- Top20%

输出：

- 交易次数
- 胜率
- 平均收益
- 收益中位数
- 最大单笔亏损
- 收益分布分位数
- 按月收益

判断标准：

- Top5% 应有最高质量，但交易次数较少。
- Top10% 通常是候选实盘阈值。
- Top20% 如果收益明显稀释，说明模型只适合严格筛选。

### 5.2 增加打分阈值评估

除了按 Top 百分比，也应观察固定分数阈值：

- score >= 0.50
- score >= 0.55
- score >= 0.60

输出每个阈值下的样本数、胜率和平均收益。

判断标准：

- 固定阈值比 Top 百分比更接近实盘使用。
- 如果不同训练批次分数分布漂移明显，需要做概率校准。

## 推荐执行顺序

1. 增加 walk-forward 验证，确认 2026/03 和 2026/04 的差异是否来自训练窗口、行情阶段或模型泛化不足。
2. 单独分析 2026/04 高分样本，检查高分信号集中在哪些股票、行业、特征区间和买点类型。
3. 增加特征组开关，做消融实验，优先验证父级别特征、本级别趋势波动特征、子级别特征的真实贡献。
4. 检查 15M 子级别特征在 walk-forward 中的稳定贡献，决定是否继续扩展子级别特征。
5. 加入交易成本后的 Top 分层收益，避免只看未扣成本收益。
6. 再做 RandomForest / XGBoost 参数对照。
7. 最后考虑固定阈值和实盘候选信号输出。

## 当前优先级最高的下一步

先实现 walk-forward 验证。

建议窗口：

- 训练至 2026/02，测试 2026/03
- 训练至 2026/03，测试 2026/04
- 后续有新数据后，训练至 2026/04，测试 2026/05

理由：

- 本次按月拆分已经证明 2026/03 和 2026/04 差异很大。
- walk-forward 可以更接近真实使用方式，避免单次切分掩盖阶段失效。
- 后续所有特征消融和模型调参，都应该以 walk-forward 的 Top 分层收益和时间稳定性作为核心判断依据。

同时建议并行准备 2026/04 失效分析：

- 高分样本所属股票分布。
- 高分样本行业或板块分布。
- 高分样本的 `parent_range`、`volatility_10`、`ret_10`、`volume_ratio_5` 分布。
- Top5% / Top10% 中止损、止盈、超时退出的比例。
- 2026/04 是否存在分数校准漂移，即高分样本的实际正样本率明显低于 2026/03。
